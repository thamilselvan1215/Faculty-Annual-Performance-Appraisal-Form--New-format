The FPI is to be computed using the performance Indices (PI) of the six components and their weights. The P.I. of the six components are computed using the marks secured in various sub components and their weights. The details are given below.

Faculty Performance Index (FPI)

FPI  =  (W1.0 * GP1)  +  (W2.0 * GP2)  +  (W3.0 * GP3)  +  (W4.0 * GP4)  +  (W5.0 * GP5)  +  (W6.0 * GP6)  +  (W7.0 * GP7)  +  (W8.0 * GP8)
